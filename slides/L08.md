# 1. HTML

---

## Elementi e attributi

```html
<p>Un <strong>paragrafo</strong> con un
   <a href="https://www.unibo.it">link</a>.</p>
```

- **Elemento**: tag di apertura, contenuto, tag di chiusura
- **Attributo**: informazione nel tag di apertura (`href`)
- Gli elementi si annidano: è un **albero** *(L03)*

---

## Lo scheletro di ogni pagina

```html
<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="utf-8">
  <title>La mia pagina</title>
</head>
<body>
  <h1>Il mio titolo</h1>
  <p>Il mio primo paragrafo.</p>
</body>
</html>
```

`lang`: la lingua · `charset`: la codifica *(L02)* · `head`: *sulla* pagina · `body`: ciò che si vede

---

## Gli elementi che servono quasi sempre

| Che cosa | Elemento |
|---|---|
| Titoli | `h1` … `h6` |
| Paragrafo | `p` |
| Enfasi | `em`, `strong` |
| Elenchi | `ul`, `ol`, `li` |
| Link | `a href="…"` |
| Immagine | `img src="…" alt="…"` |
| Tabella | `table`, `tr`, `th`, `td` |

---

## Accessibilità di base

- Titoli **in ordine**: un solo `h1`, poi `h2`, `h3`…
- Ogni immagine ha un **`alt`** che la descrive
- Un link dice dove porta: "leggi il programma", non "clicca qui"
- `lang` anche su un singolo passo in un'altra lingua:

```html
<span lang="en">"keep it simple"</span>
```

# 2. CSS

---

## HTML = struttura, CSS = aspetto

```css
h1 {
  color: darkred;
  font-family: Georgia, serif;
}
```

**Selettore** (a chi si applica) + **dichiarazioni** (`proprietà: valore`)

Collegamento nell'`<head>`:

```html
<link rel="stylesheet" href="stile.css">
```

---

## Proprietà per cominciare

| Proprietà | Che cosa fa |
|---|---|
| `color` | colore del testo |
| `background-color` | colore di sfondo |
| `font-family` | carattere |
| `margin`, `padding` | spazio fuori / dentro |
| `max-width` | larghezza massima |

```css
body { max-width: 40rem; margin: 2rem auto; line-height: 1.6; }
```

---

## Le classi

```html
<p class="nota">Attenzione!</p>
```

```css
.nota {
  background-color: #fff3cd;
  padding: 0.5rem;
}
```

# 3. Pubblicare

---

## GitHub Pages in quattro passi

1. **New** repository, chiamato `nomeutente.github.io`, **Public**
2. **uploading an existing file**: `index.html`, `stile.css`, immagini
3. **Commit changes**
4. Dopo 1–2 minuti: `https://nomeutente.github.io`

<span class="small muted">Il file si chiama esattamente `index.html`. Il repository è pubblico. Un 404? Controllate i nomi.</span>

---

## Ora tocca a voi

1. `index.html` con lo scheletro: `h1` con il vostro nome e una presentazione
2. Elenco, link, immagine con `alt`, una frase con `lang`
3. `stile.css`: colore dei titoli, carattere, larghezza
4. Pubblicate e inviate l'indirizzo al docente

---

## Riepilogo

| Concetto | In una frase |
|---|---|
| Elemento | Apertura, contenuto, chiusura; si annidano ad albero |
| Attributo | Informazione nel tag di apertura |
| `lang`, `charset` | Lingua e codifica del documento |
| CSS | Selettore + dichiarazioni = aspetto |
| GitHub Pages | Pubblica i file di un repository come sito |
